# 一架可放大观察内部的飞机

用户明确纠正：细节必须属于原始飞机模型，不能切到第二个场景或页面。本次在同一场景、根模型和相机中直接装入内部结构，移除主页面的动态详情场景入口。

任务与分工：
- 模型模块 details-model.js：替换原发动机并添加机翼、客舱、驾驶舱、起落架内部几何，均挂在原部件组；24个内部探索点，可逆局部剖视、机构动作。
- detail-parts.js：24份短英文、中文、观察提示与原理说明。
- 主控制器：连续近距离缩放、焦点、平移、自动内部显露、局部选择与原理动作；单canvas，旧任务/朗读/拆解仍可使用。
- 页面：大模型、紧凑检查栏，减少纵向跳动；手机优先保持模型可见。
- 验证：内部结构真实附着、缩放后可选、单场景/画布身份稳定、不同区域剖视、机构运动、双语、手机及原功能回归后发布。

接口：AirplaneDetails.install({THREE,model,nodes,pickables}) 返回 update({time,cutaway,region,mechanism,selected}), anchor(detailId,cameraPosition), ids。所有内部网格 userData.part 为原区域，userData.detail 为明细ID；不新建渲染器。模型、相机以 -X 为机头方向。自动剖视仅在接近当前部位时渐显，其他部位保留外观作位置参照。

教学边界：通用客机示意，内部位置/机构/级数定性简化，不对应具体机型或真实操作程序；原理控件不模拟真实飞行性能。

已实现：两个发动机的八类内部结构、客舱框架/地板/16把座椅/下层货舱、驾驶舱座椅/仪表/操纵器、机翼梁肋与铰接襟翼/缝翼/扰流板、轮轴/支柱/主轮刹车/舱口位置。原有副翼、升降舵、方向舵围绕连接处运动；起落架展示轮子转动，不模拟收放。

布局：桌面左侧为连续观察台，右侧说明独立滚动；手机阅读卡片时模型保持在屏幕上方，剖视与动作控件按需展开。单次点击选择，双击靠近；滚轮与双指可连续缩放、右键与双指可平移；缩放触发局部透明，也可以手动控制。一个 canvas、一个 scene 和一个原始飞机根模型贯穿全过程。

验证入口：`qa_labs.cjs`、`qa_models.cjs`、`qa_engine_model.cjs`、`qa_airframe_details.cjs`、`qa_discovery_progress.cjs` 验证资源与模型；`qa_rich_airplane.cjs` 验证单模型身份、24份英文、直接点选、自动剖视、机构、任务保存、触屏和旧进度迁移；`qa_labs_browser.cjs` 验证原有交互与绘本导航。`qa_engine_browser.cjs` 验证兼容保留的独立发动机旧地址。浏览器检查需要 Playwright 和 Chrome；新脚本支持 `LAB_LIVE_BASE` 验证 GitHub Pages。

2026-09-10 布局与聚焦修正：剖视、机构与拆解控件移入说明栏，视角按钮位于画布外的底部工具栏。模型使用独立固定空间，展开操作不改变画布尺寸。近看时保留当前部位（或当前细节），其余结构渐隐；对侧同类部件同样渐隐。缩回整机与拆解时恢复外观，透明部件停止投影和深度写入。材质透明状态切换同步刷新 GPU 程序，稳定状态不重复编译。`qa_airplane_layout.cjs` 检查三种屏幕尺寸、控件与画布边界及展开时画布尺寸稳定。
