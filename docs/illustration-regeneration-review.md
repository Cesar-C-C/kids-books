# 配图重制复盘与发布记录

## 端到端流程与经验

1. 先读取逐页正文、部件热点和音频键，建立唯一图片清单；11 本共 137 张图，对应 138 页，校车不再重制。
2. 每本确定角色或机械外观锚图，但逐页改变构图。总览、剖面、局部、过程和情景分别设计，不能让参考图把每页都变成相同外观。
3. 检查科学逻辑和叙事后再采用图片。发现错误进入返工队列，不因生成成功就发布。
4. 用新图实际像素校准热点。图片坐标 1216×832 与 SVG 坐标并不相同，保留共享转换和留白，使用叠加诊断图核查。
5. PNG 原图留在生成目录；上线文件统一 WebP，1216×832，quality=90、method=6。文件名追加 `_r2`，同时更新内页和首页封面；保留 jsDelivr 与同源回退。校车此前压缩由约 17.37 MB 降为约 2.10 MB，是不能遗漏的发布环节。
6. 结构、运行时、DOM 翻页/音频引用、资源解码、热点视觉检查分别验证。DOM 检查不等于真实浏览器和公网验证；上线后再核验 Pages 与 CDN。
7. Windows 沙箱中的 gh 认证失败不等于用户凭据失效。使用授权的本机环境检查 keyring；不要反复要求用户登录。先确认远端 PR 是否已合并，再决定新批次 PR。
8. 使用明确的暂存文件清单。未完成候选图和其他书的热点修改不得随已完成批次发布。新文件名避免 CDN 旧缓存，旧资源保留以便回滚。
