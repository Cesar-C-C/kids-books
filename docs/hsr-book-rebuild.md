# 依据绘本重新构造高铁模型

用户要求弃用当前高铁几何，以同主题绘本中的列车重新建模。主页面现在载入 book-model 的全新几何；不调用旧 v3/trainframe、v3/runninggear 或本地未跟踪的 _replica。延续现有实验室的页面布局和连续观察交互。

## 图片基准

- books/hsr/assets/03_nose_c_r2.webp：宽钝车鼻、饱满肩线、包覆式风挡和中央玻璃分区、独立弧边楔形侧窗、泪滴前灯、鼻盖接缝。
- 01_cover_c_r2.webp 与 02_train_c_r2.webp：暖白车体、蓝色收尖腰线、客窗、窄高车门、灰裙板、连续车厢。
- 04_carriage_c_r2.webp 与 10_driver_c_r2.webp：蓝色 2+2 座椅、走道、浅色行李架、驾驶台。
- 06_pantograph_c_r2.webp：受电弓。07_power 的放大机械示意仅作为部件参考，不用它推定轮径和车体比例。

插画有透视与绘画差异，未提供工程尺寸和全部视角。模型按可见外形重建；未展示的内部构造作教学补全，不宣称具有真实车型精确尺寸。

## 实现

外壳为沿列车长度连续变化的圆角截面；窗、腰线、灯与盖缝沿实际车身曲面投射。14 个装配组包括头车、后续车厢和可观察机构。原有 10 类部件与 25 个内部学习点继续可用。每个部件仍在同一场景中，靠近时其他装配淡化；头车内部可拆解、点选并朗读英文。

页面增加绘本图片对照与返回绘本视角按钮。新脚本、页面实际请求的版本查询参数和对照图纳入自动生成的 PWA 清单；本地 _replica 试验目录不进入部署或预缓存。

## 验证入口

- qa_book_hsr_model.cjs：14 装配、全部细节 ID、有限顶点与预算、轮轨位置、局部坐标、动作持续转动及复位。
- qa_book_hsr_visual.cjs：绘本式斜前、车头、侧面和正前渲染截图；这些是外观人工对照，不冒充像素级一致性评分。另验证首次缓存后断网重载模型及对照图片。
- qa_book_hsr_browser.cjs：连续缩放、真实双击、25 个中英文学习点、播放暂停、拆解组装、手机双指缩放、说明不遮挡、绘本与目录往返。
- qa_labs.cjs、qa_pwa.py、tools/qa_offline_manifest.py：资源、脚本和离线清单。

当前 qa_v3_hsr_browser 入口转到新模型测试，旧几何模型测试继续作为历史兼容检查。
