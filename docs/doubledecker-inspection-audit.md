# 双层巴士逐部件检查与玻璃改造

范围为 10 类部件、39 个深入条目。外观、两层座位、前门后方楼梯和黄色扶手对照 `books/bus/assets/00_cover_c_r2.webp`、`03_lower_c_r2.webp`、`04_stairs_c_r2.webp`；内部结构是通用教学示意，绘本没有提供工程尺寸。

| 部件 | 检查与修复 |
|---|---|
| 车身与玻璃 | 去除玻璃背后的实体车身板，制作上下两排窗洞、前后风挡开口和中门开口。所有 25 块窗/门玻璃与 6 个前灯透镜使用物理透光材质；镜面单独使用反射材质。 |
| 车顶 | 补回重建后为空的通风盖、手柄与排水边槽。将原本与当前模型不符的“敞篷栏杆”说明改为实际的边槽。 |
| 上层 | 补座椅支脚、底座和抓握杆；把横扶手、立杆移出靠背；走道条目有实际的地板标识。 |
| 下层 | 为楼梯入口和中门空位区移除阻挡座椅；补爱心座支脚。入口地板留出踏步凹口，轮位留出缺口并加轮罩内壁。 |
| 楼梯 | 重做六级等高梯级、防滑条、黄色边沿和连续扶手。末级衔接上层地板，入口不与座椅相交。 |
| 驾驶室 | 仪表朝向司机，补表针与刻度；方向盘与转向柱同轴，驾驶座有支座和踏板；镜头避开座椅靠背。 |
| 车门 | 前门空心边框与玻璃绕侧边铰链转动；前门、前轮拱和踏步重新对齐，清除交叉开口造成的三角形残面。中门保留关闭的玻璃外观。应急条目改为上层后窗把手，避免虚构穿过发动机的后门。 |
| 发动机 | 缩短并调整机体，为转子留出轴向间距；散热片、风扇环、转子、管路和安装脚均有实体。查看风扇时手动移开散热器观察，返回后复位。 |
| 底盘 | 保留纵梁、横撑与前后车轴，抬起车体观察，取消会切掉目标的整体剖切。 |
| 车轮 | 补真实胎面凸块和轮拱内缘，分别设置轮胎、胎面、轮毂与轮罩视角。 |

操作区保持在画布外，目录常开。缩放不会改变任何材料的透明度；玻璃的透光率是固定材质属性。近看在同一页面进行，关闭细节和重新打开时恢复正确的部件展示。

## 验证范围

- 模型检查：实际细节网格、31 处物理玻璃、窗洞射线、入口地板缺口、六级楼梯衔接与座椅间距。
- 动作检查：37 个开门/风扇位置，门扇在车身外侧扫掠，转子与机体无交叉并可复位。
- 浏览器检查：逐部件外观/打开、全部深入条目、动作截图与目标可见性；桌面、平板、手机、缩放、返回、开合和英文朗读触发。
- 可见性采样结合截图判断预设镜头，不代表任意自由旋转角度都没有正常的前后遮挡。

模型为 566 个网格、60,236 个三角形。静止时停止重复绘制，降低玻璃透射的持续开销。

本轮已通过：39 个细节的全量截图/目标可见性检查（61 张外观、打开、细节及动作图），完整浏览器交互与三种屏幕布局回归，以及玻璃细节关闭后重新打开的专项回归。独立代码复核发现的座椅/楼梯、风扇/机体、入口踏步和胎肩/地板问题均已修复；新增 2,280 个轮胎顶点对地板缺口的检查。
