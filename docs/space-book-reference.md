修正：主喷管由三只改为一只；补四片后掠尾翼；整流罩半径收至主体半径；橙带移到舷窗下方；去除穿过蓝鼻锥轮廓的长黑接缝；折叠载荷横向收小，避免穿出缩窄外壳；蒙皮归到外部层、纵向加强筋归内部层，正常展品呈完整白色箭体；涡轮泵移回发动机附近。

原有两只侧助推器在以上四图均不存在。为兼容部件发现 API 而保留，并设置 `defaultVisible = false` 与 `group.userData.optional = true`。应作为明确标识的教学扩展，仅在选中或分解展示中出现。卫星折叠方式、两瓣罩体铰接、泵叶片、具体框架数量是教学补充，不能声称由这些插画证实。

- `books/station/assets/02_overview_c_r2.webp`

概览与封面为暖银白桶状舱体、金色接环、中心节点及横向舱段；太阳翼紧凑、蓝色格面配金色细格；外侧圆形舷窗疏朗。生活页为米色内壁和机柜、蓝色竖向睡袋、绑带、固定食物桌、运动设备。

修正：补横向双舱段以恢复 T/十字轮廓；原八块长太阳板改为四块紧凑板，避免太阳翼跨度超过主体数倍；减少沿主舱密集排列的圆窗；舱体改暖银白、柜体改米色；睡袋改为竖向并对齐固定带；修正下视观察窗壳体和中心玻璃的轴向。

不同插画的太阳翼数量和位置并不完全一致，模型采用双翼概括，没有声称逐像素复刻封面。完整长桁架、散热器冷却回路、七窗观察舱、推进器组和具体柜体数量均含教学补充；上述参考图不能证明它们的工程配置。

## 实体开口与验证边界

推荐用明确的剖切窗口或移动实体盖板展示内部。火箭打开主蒙皮与罐壁；空间站同时剖开主舱、节点和衬层。需留意遮挡网格：`Inner wall`、`Tank inner wall`、`Fairing liner`、`Engine space`、`Cabin lining`、`Node lining`。实体保持不透明。

`qa_v3_rocket_model.cjs` 检查 API、几何有效性与运动复位；`qa_book_space_models.cjs` 检查绘本轮廓回归、太阳板尺度、睡袋方向与空间站复位。浏览器效果由主任务统一验证，以上静态检查不代表视觉验收。
