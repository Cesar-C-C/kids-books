## 实体开口与验证边界

推荐用明确的剖切窗口或移动实体盖板展示内部。火箭打开主蒙皮与罐壁；空间站同时剖开主舱、节点和衬层。需留意遮挡网格：`Inner wall`、`Tank inner wall`、`Fairing liner`、`Engine space`、`Cabin lining`、`Node lining`。实体保持不透明。

`qa_v3_rocket_model.cjs` 检查 API、几何有效性与运动复位；`qa_book_space_models.cjs` 检查绘本轮廓回归、太阳板尺度、睡袋方向与空间站复位。浏览器效果由主任务统一验证，以上静态检查不代表视觉验收。


## 第二轮：以单张主参考重建外形

主参考固定为火箭 `01_cover_c_r2.webp` 和空间站 `02_overview_c_r2.webp`。重开这两张图、火箭结构页以及上一轮 `.qa-labs/rocket-exhibit-whole.png` / `station-exhibit-whole.png` 对照后，确认上一轮的直锥尖头、粗金属环、站体后延段和高架散热结构仍偏离绘本。

火箭重新收细主体（直径0.92，蓝鼻底径0.80），蓝鼻用25个纵向轮廓点生成连续弧面，去掉尖端圆柱小柱。环缝减薄，底裙改象牙白，喷管缩短、口径缩至0.60，尾翼总宽约1.54。收紧舱内卫星折叠宽度，避免太阳板边缘从舷窗附近穿出。主模型鼻尖至主喷管底约7.92，长径比约8.61；封面粗略像素读数为总长约530、主体宽约60，约8.8。鼻部高度1.14约占主模型14.4%，与封面约72/530=13.6%接近。像素边界受画笔和透视影响，这些是视觉校准范围，不是工程尺寸或逐像素相等的证明。

空间站删除原来沿+X伸出的虚构后舱，改成中心节点、单根长前舱、两根横舱的T形关系。节点至前端4.25、舱径1.29，比例约3.29；主参考前舱投影中心线约500像素、桶身宽约150像素，约3.3（透视下仅作粗校准）。太阳翼改为左翼在横舱端、右翼在长前舱侧，两翼各两块紧凑蓝金网格板。机械臂移到右横舱上沿并折向外下方，停用竖直天线式姿态。去掉对接面的大白十字，改同心环与小圆心。细化舱体纵缝、接环与铆点。

`truss`、`radiator`、`cupola` 三个教学组件已与助推器一样设为可选，默认完整外观不得出现。仍保留各自的部件和课程API，选中教学扩展时可以展示。主参考没有这些高架交叉散热板、长外露桁架或下挂七窗观察舱，不能让它们改变默认轮廓。

本轮静态回归增加T形单前舱、扩展默认隐藏、弧面鼻锥、去白十字和火箭长径比检查。浏览器最终镜头、遮挡和表面外观仍须主任务统一验证；没有宣称已达到像素级1:1。

第三次截图检查：测得折叠太阳板边缘世界半径0.450，超过火箭头舱半径0.400，确认为舷窗上方灰色突出物；进一步缩小折叠载荷横向比例并增加逐顶点内包络测试。空间站太阳板保持蓝色、金色细网格，将电池面粗糙度设0.86、金属度设0，消减展台强光导致的白色反光；最终蓝色可读性需新截图确认。
