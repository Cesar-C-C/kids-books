# 儿童绘本开发项目整理设计

> 后续决策（2026-09-15）：用户在整理完成后明确要求删除全部 HeyGen 配音试验，`workbench/cloud-voice-heygen/` 已永久删除。下文保留的是当时的迁移设计和执行依据，不再代表当前项目状态；当前事实以 `docs/STATUS.md` 为准。

## 目标

把 `儿童绘本开发` 从“空外层仓库套多个历史副本”的工作区，整理为一个可直接开发、测试和发布的 Git 仓库；保留唯一有效主线和可证明仍有价值的未完成工作，删除可再生成或已被主线取代的副本、缓存和临时产物。同时建立稳定的项目说明与会话分工，使旧会话删除后仍能恢复关键上下文。

## 当前事实

- 外层 `儿童绘本开发/.git` 没有提交、没有远端，不能代表产品历史。
- `kids-books-cloud` 的 HEAD 为 `f9aea94`，与本地 `origin/main` 一致，是当前主线的最佳基准；它是依附于 `kids-books/.git` 的 linked worktree，不是可单独移动 `.git` 的独立仓库。
- `kids-books` 落后 `origin/main` 25 个提交，并包含 77 个学校巴士音频删除和一套被当前主线替代的高铁交互试验。
- `kids-books-opaque` 干净但落后 `origin/main` 5 个提交；其语音提交已包含在后续主线历史中。
- `kids-books-engine`、`kids-books-inline`、`kids-books-rich` 都是没有首个提交的整仓实验快照。
- `airplane-3d`、根目录一次性脚本、补丁、技能备份、虚拟环境和 `outputs` 是早期独立试验或可再生成产物。
- `kids-books-cloud` 内有一组尚未提交的 HeyGen 云朵配音试验脚本、进度文件和少量暂存 WAV；它们是唯一明确需要保留的本地 WIP。

## 目标目录

整理后，项目根目录直接就是 `kids-books` Git 仓库：

```text
儿童绘本开发/
├─ .git/                  # 来自当前 kids-books-cloud
├─ .github/               # CI 与 Pages
├─ books/                 # 双语互动绘本及正式资源
├─ labs/                  # 3D 科普实验室
├─ shared/                # 阅读器与通用样式
├─ tools/                 # 可复用生成、检查与发布工具
├─ docs/                  # 项目说明、决策和工作记录
├─ workbench/             # 明确标记的未完成本地试验
├─ index.html             # 正式入口
└─ PROJECT.md             # 项目地图与协作入口
```

`workbench/` 不参与正式入口、PWA 清单和发布。云朵 HeyGen 试验的脚本、进度、清单和暂存 WAV 统一放入 `workbench/cloud-voice-heygen/`，并在其中写明状态、恢复方式和退出条件。生产音频仍只放在 `books/*/audio/`。

## 保留、迁移与删除

### 保留并提升到根目录

- `kids-books-cloud` 的完整 Git 历史、当前工作树和正式产品文件。
- 当前未提交的云朵 HeyGen 配音试验，但从正式资源目录迁入 `workbench/cloud-voice-heygen/`。
- 既有 QA、PWA、生成和发布脚本，只要仍被当前入口、文档或验证命令引用。

### 删除

- 外层空 Git 元数据；用从本地对象库创建的无硬链接独立克隆取代。
- `kids-books`、`kids-books-opaque`、`kids-books-engine`、`kids-books-inline`、`kids-books-rich` 五个重复或过期仓库。
- `airplane-3d` 早期独立副本。
- `.edge_tts_venv`、`.cosyvoice-runtime`。环境必须通过文档化命令重建，不随项目长期保存。
- `outputs` 中已接入正式资源或仅用于验证的生成产物。
- `.skill-backups`、`skill-review`。已安装技能不属于产品仓库。
- `finish_hsr.py`、`redesign_hsr.py`、`upgrade_exhibits.py`、`hsr-opaque.patch` 等根目录一次性迁移脚本和补丁。

删除前先从本地 `kids-books` 对象库对 `codex/cloud-journey` 创建 `--no-hardlinks` 独立临时克隆，迁入 WIP 和文档，并验证新克隆的 HEAD、远端、对象完整性及工作树内容。再次验证每个绝对路径位于 `儿童绘本开发` 内后，才替换外层目录并删除其余副本。删除采用 Windows 原生 PowerShell 文件操作，避免跨 shell 拼接路径。

## 项目文档

新增或整理以下长期文档：

- `PROJECT.md`：产品范围、正式入口、目录地图、常用命令、当前线上地址和协作规则。
- `docs/STATUS.md`：当前发布基线、已完成能力、明确的 WIP、已知风险和下一步。
- `docs/CONVERSATIONS.md`：会话分类、命名方式、允许范围和跨类问题的拆分规则。
- `workbench/cloud-voice-heygen/README.md`：该试验的来源、完成度、输入输出、恢复步骤和清理条件。

文档只记录当前可行动事实，不复制长篇会话历史。历史提交、PR 和上线状态必须区分“已验证”“仅生成”“未做浏览器 QA”。

## 会话架构

项目长期保留五类任务；一个任务只负责一类问题：

1. `项目规划与集成`：版本路线、目录规范、跨模块接口和总体验收。
2. `绘本内容与插画`：故事、科学内容、页面、热点、插画和双语文案。
3. `3D 科普实验室`：模型、拆解、部件交互、Three.js 和实验室专项 QA。
4. `配音与音频`：TTS、声音选择、音频生成、清单、压缩和播放降级。
5. `测试、发布与线上问题`：静态检查、浏览器 QA、PWA、Git、PR、Pages 和缓存排查。

新任务标题使用 `[类别] 具体目标`，例如 `[配音与音频] 完成云朵绘本角色配音`。出现跨类需求时，由“项目规划与集成”任务拆分，不在同一任务里混做。整理完成后可创建这五个新任务；旧任务由用户验收后自行删除。

## 关键状态记录

必须写入 `docs/STATUS.md` 和 Codex 记忆：

- 主仓库远端、基线提交和正式入口。
- 云朵绘本滑动/PWA/配音现状，以及 HeyGen WIP 的真实完成度。
- 3D v3 实验室预生成音频的提交历史，以及此前未完成运行时播放 QA 的事实；若当前主线验证通过，再更新状态。
- 学校巴士封面、R2 资源与实际引用之间的历史风险，强调“生成文件存在不等于已接入”。
- 发布前必须检查 Git 根目录、分支、远端、未提交改动、主动资源引用、静态 QA、浏览器 QA 和线上地址。

## 验证

整理完成后分层验证：

1. 结构：根目录只有一个 `.git`，不存在嵌套仓库和计划删除的目录；Git 顶层就是 `儿童绘本开发`。
2. Git：分支、HEAD、远端和 `origin/main` 关系符合迁移前记录；仅出现预期文档和 WIP 变更。
3. 静态：运行项目已有的全库绘本、运行时、实验室、PWA 和资源引用检查。
4. 浏览器：验证首页、至少一个普通绘本、云朵绘本、学校巴士绘本和 3D 实验室；同时覆盖桌面及移动视口。
5. 资源：确认正式入口加载正式资源，`workbench/` 未进入 PWA 或发布清单，音频和图片不存在断链。

不进行线上发布，因此不会把本地浏览器通过描述为线上已发布。任何未能运行的测试单独列出原因。

## 安全边界

- 不提交、不推送、不创建 PR。
- 不删除或归档现有 Codex 会话。
- 不改变线上 GitHub Pages。
- 不把未完成 HeyGen 配音接入生产页面。
- 遇到主线与盘点结果不一致、WIP 文件新增或路径越界时停止删除并重新核查。
