# 地面为什么会摇 儿童互动绘本与配套实验室衔接草案

日期：2026-10-01。状态：待用户审阅，仅设计，不是已实现或已验收功能。

## 已认可方向与本轮范围

用户整体认可小穿山甲岩岩在自然博物馆帮助制作“会动的大地”展品的故事方向，并要求强化互动性。本稿将互动细化为“先猜一猜 → 自己操作 → 看见因果 → 再试比较”，新增细节尚待认可。

新增要求：在3D实验室同步制作更详细的原理和模型互动。本稿负责绘本及双向衔接，实验室由对应任务独立编写设计；同步指同一主题协同交付，不默认实时共享模拟状态。

配套设计见[地震3D实验室草案](2026-10-01-earthquake-3d-lab-design.md)。任务间统一默认断层和深链接口，接触条件对照仅留在实验室可选深看；两份草案仍待用户书面审阅，不是产品实施许可。

默认面向4–8岁、中英双语、Fun-CosyVoice3预生成配音。成功标准不是完成点击次数，而是孩子能够指出：哪里卡住、哪里变形，突然滑动后什么向外传播，以及标记岩石有没有一路跑走。年龄适配目前是设计判断，未经儿童实测。

本轮只新增此设计文件。未创建工作树、修改产品、生成图音或提交发布。当前主目录处于旧的codex/cloud-journey分支且有空间站等未提交工作；声音／肥皂另有工作树。后续实施须重新核实集成基线，不从主目录旧阅读器直接复制，不改动现有未完工作。

## 方案选择

推荐“故事中的两个小实验台”：一个解释突然滑动如何发生，一个解释振动如何传出去，最后由岩岩请孩子帮助布展。比单纯逐步演示更有选择和验证空间，同时保留低龄儿童可直接观看的路径。

不选多参数自由模拟器：孩子容易只追求更剧烈效果，变量混杂且科学验证成本过高。不选热点问答为主：能增加点击，但不一定让孩子观察到自己操作与结果的联系。

主流程不加入建筑抗震、海啸、震级、灾难得分、预报系统或多种断层分类。震源／震中和波型术语不设为通关知识。

## 故事和网页结构

采用连续故事与局部实验台交替，而非强制固定页数或默认阅读器。正文和互动不同时占据两块远离的屏幕。

1. 岩岩收到布展任务，发现静止的模型还解释不了“为什么会摇”。开场一句“这是我们在馆里慢慢观察的大地模型”建立情境。
2. 第一个实验台：岩岩想推动模型，却发现接缝附近暂时没滑，旁边的岩石已经变形。孩子参与加载和观察。
3. 岩岩捕捉到突然滑动的瞬间，保留错位的纹路作证据；孩子可以暂停、慢放或同条件重试。想比较接触条件，可选进入实验室深看。
4. 第二个实验台：岩岩把观察标记放在不同位置，孩子猜到达次序，追踪一小块岩石的运动。
5. 布展收尾：孩子帮助安排三张动态展卡，或直接看岩岩完成展览。成功结尾不依赖答题正确。

每个实验卡内部顺序为简短目标、主要画面、紧邻画面的操作、持续可见的一句结果。预测只需一至两个图文选择，可直接“先看看”。进阶解释折叠在实验后，来源和比例／时间简化集中于成人笔记，不在正文反复提示“示意图”。

## 科学依据与表达边界

本书选取构造地震中断层突然滑动这一机制，不声称涵盖所有地震成因。局部断层受摩擦锁住时，周围岩石仍可形变；滑动释放的部分能量形成地震波。依据：[USGS 地震成因问答](https://www.usgs.gov/faqs/what-earthquake-and-what-causes-them-happen)。

地震波传播与介质局部运动是两件事；震源不应画成从地表发射的魔法按钮，也不能把预测实验结果等同于预测现实地震。依据：[USGS The Science of Earthquakes](https://www.usgs.gov/programs/earthquake-hazards/science-earthquakes)。查阅日期：2026-10-01。

以下实验规则是教学设计提案，不是上述来源提供的数值地震模拟方案。力学参数、时间压缩、位移放大及均匀介质都是模型假设。正式实施前须通过模型层检查，不能用动画看起来流畅代替科学验证。

岩岩没有动物预报能力，也不钻进真实断层。无倒塌、尖叫、突然巨响、闪屏、整页震动或设备振动。作品讲原理，不作为灾时避险指引。

## 核心实验一 断层试验台

### 孩子能做什么

主问题：“接缝卡住时，旁边会怎样？”预测选项为“也都不动／旁边慢慢变形”，配短动画缩略图，另有“先看看”。选择只保存猜想，不改变物理结果。

| 操作 | 实际改变什么 | 画面反馈在哪里 | 可以验证什么 |
| --- | --- | --- | --- |
| 按住“慢慢推动模型” | 以固定低速移动模型远端驱动边界，不直接移动断层两侧 | 驱动箭头、接缝和周围纹路在同一画面 | 推动时接缝可以暂时锁住，而纹路已经弯曲 |
| 点击“推一小步”或键盘激活 | 同一驱动量的小增量，不累积隐藏点击奖励 | 与按住完全相同的状态和反馈 | 不会长按也能做相同实验 |
| 松开推动 | 只停止增加驱动位移 | 箭头停止；若已滑动，局部运动自然收尾 | 松手不是“触发地震” |
| “暂停观察／继续” | 停住／恢复模型时间，不改物理状态 | 保留变形、错位和当前短句 | 能在关键瞬间仔细看，而不是必须反应很快 |
| “慢放重看” | 重放刚才的状态记录，禁用加载 | 同一画面叠加细淡的原位置轮廓 | 突然滑动前后哪里改变，哪里留下错位 |
| “同样条件，再试一次” | 恢复同一初态和同一接触条件 | 清除上一轮运动，保留可选重播入口 | 重复观察加载、变形和突然滑动的因果关系 |

绘本只有一个固定的锁定后滑动预设，不显示接触条件选择。重播使用同一状态记录，重试恢复相同条件但允许孩子再次驱动；不把两次不同手动操作宣称为单变量比较。接触条件对照仅放在3D实验室可选深看，不是读懂绘本的前提。

结果短句示例：“接缝还没滑，旁边的纹路已经弯了。／The fault is still stuck. The rock beside it is changing shape.” 滑动后：“这里突然滑了，纹路留下了错位。／It slipped suddenly here. The markings stayed offset.” 不显示能量满格、危险百分比、倒计时或“再点三次就地震”。

### 最小模型与科学风险处理

默认统一为向内挤压＋逆断层的二维侧剖面，上盘相对下盘沿倾斜断层面上移，与3D实验室一致。驱动、受力与几何关系由专业任务核验，不要求用户用选择断层类型来修正科学矛盾。不混用纯走滑的侧剖面、上下错动和火山爆裂。画面保持同一地表、同一地下纹路及同一局部锁定区。地表不必裂开，不能暗示每次地震都造成地表开裂。

建议用“弹性加载＋摩擦滑块”教学近似产生状态，再把状态映射为岩体纹路形变；不要用固定播放到第几秒触发滑动。驱动位移、弹性形变量、断层滑移量分别存储。摩擦承载条件控制锁定／滑移转换；模型中确有阈值，但不向儿童包装为现实可测的预报门槛。

绘本不实现接触对照。实验室的可选对照及其单变量验证门槛详见配套设计；不能把粗糙度当作唯一原因，也不推出“平稳滑动永远没有地震”。两端共享基本机制，不要求共享一组可变运行状态。

暂停冻结时间，松手冻结驱动，两者必须分开。发生滑移后保留永久错位；可以恢复部分弹性形变，但不让整个场景自动恢复成从未滑动。单轮首次事件收尾后停止接受新的加载，提供重播／再试，避免持续按住产生无限连锁摇晃。

对4–5岁优先保留“推一下—看纹路—慢放重看”，成人可伴读；6–8岁或有兴趣儿童可重复观察后进入实验室深看，不设年龄锁。

## 核心实验二 追踪地震波

### 精简交互

延续同一剖面，岩岩在地表放两面“感应旗”。旗是虚拟到达指示器，不冒充真实地震仪，也不通过旗子摇得更大表示更危险。

提供地表左、中、右三个固定大落点。先选旗A，再选落点；选旗B，再选另一个落点。初始自动放好一近一远，孩子不操作也可开始。拖放可作为增强，但点选、按钮与键盘具有完整等价功能；无需像素级对齐。

| 操作 | 改变什么 | 可见结果与验证 |
| --- | --- | --- |
| 放置两面旗 | 改变观察位置，不改变震源或释放能量 | 旗明确吸附到落点，邻近文字读出位置 |
| 猜“A先／B先／一起／先看看” | 只保存预测 | 回放结束将预测与观察并列，不强制判分 |
| “开始观察” | 重播固定的一次波动事件 | 波前先到的位置先亮起“到了”，到达标记持续保留 |
| 选择一个地下标记点 | 只改变追踪对象，不施加力 | 标记与其静止轮廓同屏，附近有短位移轨迹 |
| “暂停／下一小步” | 暂停或推进同一模型时间 | 波前在另一处时，标记仍只在原位附近振动 |
| “交换两面旗，再试” | 交换A/B位置，事件与介质不变 | 先后随位置而变，不是“A永远先” |

固定事件开始后禁止挪旗，提示“这一轮看完再换位置”；暂停后可以继续，重置才清除到达记录。增加等距落点用例，允许真实显示“一起”，不强造胜负。

### 模型边界

第一版只表现均匀、各向同性介质中的一个简化体波脉冲，不增加P/S波切换、地层反射或折射。传播计时依据震源到点的距离和固定模型波速，局部位移只在脉冲到达后出现；波前不是一圈实体岩石。波源取断层内部固定起始位置，不在地表按钮处；有限断层破裂的扩展、复杂波场不在该脉冲模型中计算。

圈状轮廓表示剖面中的波前位置，不等同水面真实形态。标记点的振动与断层永久错位分属不同状态，不能用“每块石头都回原位”总结整个地震过程。

成人笔记说明该均匀单波型模型里，同源传播距离短的旗先收到信号；不能据此推断所有真实场地的到时关系，更不能推导“越远越安全”。页面不给安全距离或现实时间换算。

## 轻量收尾 帮岩岩布展

三张卡分别呈现“卡住时旁边形变”“突然滑动”“振动向外传播”。默认静帧，点击“看这张动起来”才播放短动作，避免三张同时动。

孩子依次点卡放入第1、2、3展位，也可用前移／后移按钮调整；拖动不是唯一入口。“看看展览”播放排列结果并给一条具体线索，例如“先找旁边纹路慢慢弯的那张”。可修改、重试或直接选择“请岩岩帮忙布展”。没有分数、失败惩罚或阅读锁。

排序只帮助复述，不作为唯一理解证据。全部互动都可以跳过，故事仍完整。

## 同屏布局与无障碍替代

角色和博物馆环境在背景／侧边叙事层，剖面与按钮在独立模型层。不得把大面板叠在角色脸或手上；交互物体采用透明素材，标签用HTML/SVG，不烤进图像。

手机实验画面优先占宽，目标一句、操作一排、结果一句紧靠模型。预测完成后折叠为一行；暂停／慢放等次级控件进入明确的“观察工具”，保持每阶段一个突出主动作。两个实验不共用远处浮动控制台。

320px宽和横屏短视口下，压缩环境插画、允许说明展开，保留模型、当前主按钮与当前结果；必要时切到紧凑实验视图，而不是把画面缩成无法看清的缩略图。不锁整页滚动，不抢浏览器缩放。点击目标至少44px，焦点可见，颜色之外同时使用文字／形状。

减少动态效果：用同一状态序列的离散关键帧替代摇动、平滑变形和传播动画；“下一小步”推进，显示变形前后轮廓及到达次序，不能退化为缺少证据的一段说明。普通模式也随时可暂停。

默认静音，无震动音效需求；声音不是任何题目的答案线索。结果通过持久文字和适量aria-live状态告知，不逐帧播报。失焦、指针取消、切语言、开始朗读、离开页面均取消持续输入和过期回调；失焦后不自动恢复加载。朗读不自动启动实验。

## 内容与音频契约

### 绘本与3D实验室分工

绘本自身讲完整因果链，两个实验可独立完成。实验室承接可旋转／剖切的岩层、弹性回弹、震源震中、断层类型和P/S波的分层深入；具体首版范围与科学验证由实验室设计负责。本稿不把这些功能视为已经承诺全部实现，也不借此扩大绘本主流程。

绘本断层实验后提供“去实验室，换个角度看岩层”；波实验后提供“去实验室，仔细看振动”。入口是可选延伸，不弹窗强推、不作为阅读完成条件。另有“继续故事”留在当前页面。

双方固定以下设计接口（项目根目录相对路径，尚未实现，不是现在可用的网页）：

| 绘本出发章节 | 进入实验室 | 返回绘本 |
| --- | --- | --- |
| 断层试验台 | `labs/earthquake/index.html?lang=zh&from=earthquake-fault#elastic-rebound` | `books/earthquake/index.html?lang=zh#fault-lab` |
| 追踪地震波 | `labs/earthquake/index.html?lang=zh&from=earthquake-waves#waves` | `books/earthquake/index.html?lang=zh#wave-lab` |

英文使用`lang=en`。只允许`lang=zh|en`与`from=earthquake-fault|earthquake-waves`，不接收任意returnUrl、模拟参数或进度。实验室内切卡不改进入时的返回章节；无来源直接打开实验室时，返回绘本开头。非法语言回落中文、非法来源按无来源处理，非法目标锚点回落首卡。返回采用当前选定语言，未切语时自然保留入场语言。新入口未就绪前不注册为可用页面。

例如从断层章节以中文出发，实验室记住来源章节；未切语时返回该章节的中文版，在实验室切成英文后则返回该章节英文版。模型状态重新初始化，明确“可再试一次”，不假装恢复刚才的加载／滑移。浏览器后退若恢复快照也必须处于暂停状态。新页面不自动发声、不自动加载驱动。实验室未缓存且当前离线时，绘本内保留完整故事与两个实验，入口显示“联网后可进入实验室”及继续阅读选项，不导航到不可用页面；加载失败也允许返回绘本，不能留下空白画布。

双方共用概念键提案：`fault`断层、`elastic-strain`弹性形变、`slip`滑移、`focus`震源、`epicenter`震中、`wavefront`波前、`particle-motion`局部介质运动、`p-wave`P波、`s-wave`S波。儿童短句可以更浅显，但概念键及成人术语一致。不得把地表点叫作震源。

视觉约定提案：岩体暖土色，断层深赭红，通用波前青蓝，追踪点橙黄且有深色描边；实验室P/S波需再用形状／线型和标签区分。所有颜色应经对比度检查，绝不只用红绿或颜色表达先后／对错。这里只共享语义约定，不共享可变运行时或互改对方文档。

衔接验收包括：两种语言从两章节直达正确实验，返回原章节／语言；非法参数安全回落；离线只下载绘本时仍完整阅读；减少动态效果偏好两端一致；导航中无残留音频或加载；不要求跨页面同步积分、预测选择或物理参数。

### 双语和正式配音

建议独立bookId为earthquake，实施时先检查是否占用。以单一版本化双语内容源保存场景、词汇、预测提示、控制标签和有限结果句；每条稳定ID、中文、英文、内容版本及是否需要录音都明确。模型只产生语义状态ID，不拼接临时待朗读段落。

正文、核心问题与关键观察结论纳入正式Fun-CosyVoice3朗读；短按钮标签由文本和无障碍名称承担，点击不自动发声。给互动问题／结果提供显式“听这句”。不为每一帧或每一种位置组合生成音频，不沿用声音／肥皂的固定片数。

当前场景音频清单契约只覆盖scene/vocab；若新增互动话语，正式设计实施阶段需由音频与QA共同扩展有类型的prompt/result条目、导出器、播放器和PWA验证，不能仅把MP3放入目录就算接入。内容未冻结不批量生成；变更已录文本必须标为待更新。

## 模块边界与验证方案

拟分为纯模型状态层、实验视图／输入层、双语内容层、统一播放与取消层。物理／时间逻辑不得依赖DOM帧率或按钮点击次数；模型参数不暴露为儿童多参数控制台。具体文件与实现步骤在草案获批后另写实施计划。

| 验证层 | 必须观察或断言的结果 |
| --- | --- |
| 断层模型 | 锁定时滑移近零但弹性形变增加；不同时间步的结果可收敛；松手不强制触发；暂停不改变状态；滑动后保留错位；单轮有界结束 |
| 同条件重试 | 重试恢复相同初态和接触条件；慢放重播保存的状态记录；绘本中没有接触预设控制或虚假的公平比较结论 |
| 波传播 | 不在波前到达前振动；同源均匀模型的近／远／等距到达正确；交换A/B只交换记录；追踪点不随波前平移 |
| 输入等价 | 长按、单步和键盘走相同状态路径；pointercancel／失焦停止驱动；无精确拖放依赖；手机竖向滚动不被误判成操作 |
| 结果和重试 | 预测不修改结果；答错给对应证据；重置不留上一轮到达标记或异步提示；跳过仍可读完整故事 |
| 运行生命周期 | 暂停、慢放、重播互斥；切语言／朗读／离页取消回调；恢复后无后台自动触发；快速连续点击不重复释放事件 |
| 浏览器与资源 | 中英320/390/820/1024宽及短横屏无溢出；关键操作与结果同屏截图；减少动态效果、键盘和读屏基本路径；真实离线图片／音频／模型资源齐全 |
| 可理解性 | 在家长同意且有陪同的后续观察中，请孩子指出卡住处、变形处，解释标记点是否跑走；记录需要成人提示的位置，不以答对排序代替理解 |
