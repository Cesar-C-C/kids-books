# 校车逐部件检查与玻璃改造

范围：校车实验室的 10 类部件、39 个深入条目。以绘本的部件图和车厢图核对外观，内部机构为通用教学示意，图片并未提供工程尺寸。

| 部件 | 原问题 | 处理 |
|---|---|---|
| 车身和窗户 | 实心板上贴蓝色窗片，玻璃背后还有整块钢板 | 真正挖出窗洞、环形窗框；前风挡、驾驶员窗、十扇侧窗、四块入口玻璃、两扇后窗和安全门玻璃统一使用透光反射材质 |
| 车顶 | 逃生窗、顶部条目为空 | 补逃生窗框、盖板、手柄与车顶弯梁，逐条目聚焦 |
| 发动机舱 | 打开后只有空洞，保险杠和灯也跟着移走 | 为舱盖、格栅、灯、保险杠分别设置观察位；补发动机、安装梁、管路、散热片及风扇 |
| 驾驶室 | 仪表朝错方向，近看时被舱盖挡住 | 从驾驶员侧观察，补仪表指针、方向盘轮辐、踏板和驾驶座支座 |
| 车门 | 两扇门共同绕中点旋转，玻璃背后是实心门片；后门被尾板挡住 | 门框有真实开口、铰链固定在两侧门柱；后门与中央通道对齐并可独立演示 |
| 踏步 | 高度不连贯，被关着的门遮住 | 三级防滑踏步与地板衔接，观察时打开入口门 |
| 座椅 | 安全带是漂浮的短条，尾部横排堵住逃生路线 | 补肩带、腰带、带扣和支架底板；保持中间过道畅通 |
| 过道 | 长扶手穿过所有座椅靠背 | 改为入口短扶手；按地板纹理、扶手、尾部通道分别观察 |
| 停车牌 | 镜头被车身挡满；臂与牌的安装朝向不合理 | 重做侧面铰接臂、白边八角牌与字样，固定侧面镜头并验证动作范围 |
| 警示灯 | 演示缺失，所有细节共用远镜头 | 分别观察红灯、黄灯与灯座，并提供点亮演示 |
| 车轮 | 打开时剖掉目标轮组，花纹条目只是圆环 | 不再切掉轮组；补胎面凸块、轮罩内缘，针对单个轮胎/轮毂设置视角 |

缩放不会改变其他部件的透明度。玻璃的透光是其固定材质属性。目录保持展开，标签固定在画布角落；观察内部需要主动打开覆盖件。

## 内容依据

删除“行驶中扶着过道行走”“两人同时上车”“高靠背意味着不必系安全带”等引导，改为停稳、得到司机允许后依次上下车、使用扶手、坐好并正确使用车上配备的安全带。安全内容参考 [NHTSA School Bus Safety](https://www.nhtsa.gov/road-safety/school-bus-safety)。警示灯对应绘本中的美式校车示意，实际道路规则依所在地区而定。

## 验证

- `qa_v3_schoolbus_model.cjs`：实体条目覆盖、玻璃材质、真实窗洞、中央通道、门扇扫掠范围与复位。
- `qa_schoolbus_inspection.cjs`：逐部件外观、打开、全部细节截图与目标可见性采样。
- `qa_exhibits_browser.cjs`：双语内容、开合、返回、缩放、手机与平板布局。

可见性采样与截图用于发现当前展示视角的问题，不代表任意自由旋转角度都没有正常的前后遮挡。

本轮结果：模型为 428 个网格、45,520 个三角形，21 处物理玻璃（19 块车窗玻璃与 2 块前灯透镜）。完整截图检查覆盖 10 类部件、39 个细节及机构动作；发现的问题修复后补拍复核。39 个细节的取景与可见性采样通过，车门在 37 个动作位置均不碰撞踏步。桌面、平板、手机的完整浏览器回归通过，含目录常开、近看/返回、开合复位、双指缩放和英文朗读触发。

玻璃使用固定透光率、折射率、厚度与环境反射，车身不会随放大变透明。镜头静止时暂停重复绘制，减少玻璃透射的持续渲染开销。
