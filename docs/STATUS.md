## 每次工作前的检查顺序

1. 确认 Git 顶层、分支、HEAD 和远端。
2. 查看全部已修改、已删除和未跟踪文件，避免混入其他任务。
3. 确认修改的是正式入口真正引用的资源，而不是历史副本或仅生成文件。
4. 运行对应静态 QA；涉及交互时再运行浏览器 QA。
5. 发布需另行授权，并在远端提交、Pages 构建和最终 URL 三处确认。
