# 飞机逐部件检查与修复

本轮只优化飞机实验室，基线为 0595bdb。检查范围为 10 类部件、15 个实体组件、30 个继续探索条目。内部装置是通用客机的教学示意，不对应某个机型的工程尺寸。

## 逐项处理

| 部件 | 实際检查发现 | 本轮处理 |
| --- | --- | --- |
| 机身 | 框架、座椅、地板、货舱共用远镜头，机翼挡住地板和行李 | 分别定位前客舱的框架、座椅排、地板与行李；在主动打开的状态下剖开近侧框架，保留远侧连接；补座椅头枕、安全带和行李提手、绑带 |
| 驾驶舱 | 仪表和操纵装置被椅背及后方客舱框架挡住 | 驾驶舱单独打开；为座椅、显示屏、操纵装置各设侧上方镜头；补油门手柄与头枕 |
| 机翼 | 整个外层一起移动，襟翼、缝翼和扰流板随蒙皮飞走；固定翼面与活动面重叠 | 固定蒙皮独立分组；按弦向与展向分开固定翼面、襟翼、副翼、缝翼和扰流板窗口；翼肋止于活动面前方；活动面保留安装位置 |
| 发动机 | 八个入口共用斜视镜头，风扇挡压气机，核心挡转轴 | 进气口/风扇正视、喷口后视、压气机/涡轮侧视；燃烧室/转轴采用固定纵向剖面；提高深色风扇的可读性 |
| 起落架 | 整体剖切切掉支柱和轮组；刹车被轮胎隐藏 | 取消整个起落架剖切；各细节定位到具体轮组或舱口；仅查看刹车时移开对应主轮，离开后精确复位 |
| 垂直尾翼 | 有骨架却没有探索条目 | 增加垂尾骨架条目与专用视角；移开的蒙皮停放在镜头后侧 |
| 水平尾翼 | 翼梁入口缺失，移开的尾翼蒙皮挡住翼梁 | 补翼梁入口；改变蒙皮移开方向，保留翼梁和升降舵安装关系 |
| 副翼 | 缺少探索入口，左右动作需要核对 | 补铰链与传动连杆条目及实体铰链、随动伸缩杆和连接环；连杆从下方观察，左右副翼反向偏转 |
| 升降舵 | 缺少探索入口，镜像铰链轴导致两侧偏转相反 | 补铰链入口与几何；修正符号，使两侧同向偏转 |
| 方向舵 | 缺少探索入口，打开操作直接剖掉舵面 | 补铰链条目与实体连接，取消无意义剖切，播放左右偏转 |

## 交互与内容

- 缩放只改变距离；结构开口由主动操作触发。周围部件不做自动透明化。
- 目录保持用户的展开状态。部件名称移到画布角落，不压在目标结构中间。
- 去掉已经不存在的“剖切滑杆”提示；每个条目都有英文介绍、中文辅助、观察提示和原理。
- 展开后只演示当前选中的翼面机构；完整副翼和升降舵保留成对动作。返回部件恢复观察焦点，合上恢复模型安装位置。

## 验证方法

`qa_airplane_inspection.cjs` 通过真实 Chrome 打开每个部件、展开并点击全部细节；补查左侧镜像组件。保存画布截图和 `visibility.json`，从相机向目标几何采样点发射射线，核对目标在画面内且具有可见表面。射线检查只能发现被完全遮挡等问题，不能代替截图复核，也不意味着任意自由旋转角度都不存在正常的前后遮挡。

`qa_v3_airplane_model.cjs` 检查所有内容均映射到实体几何、各部件均有深入条目、翼面动作方向、独立机构演示、机轮移开与复位，以及几何和网格预算。`qa_exhibits_browser.cjs` 检查缩放、视角返回、开合复位、英文内容、桌面/平板/手机布局及双指操作。

截图位于本地 `.qa-labs/airplane-audit/`，包含部件外观、展开、细节与左右侧对照。最终浏览器检查结果应以实际运行输出为准。

最终本地验收：全量检查生成73张图，30个条目连同镜像侧共47组几何可见性检查通过；局部改动另行复测。738个网格的版本补齐随动连杆后为748个，仍低于750预算。翼梁与翼肋逐顶点包络测试通过；30条双语内容、桌面/平板/手机开合与缩放回归通过。
