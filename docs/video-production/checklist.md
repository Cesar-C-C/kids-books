# 科普视频验收清单

- [ ] 范围：年龄、主问题、具体系统、简化与排除项清楚；事实—第一方来源—场景逐项对应。
- [ ] 分镜：每个主要镜头揭示变化；没有长静图讲解、固定文字侧栏、自动整句知识卡。
- [ ] 几何：连接/支撑/尺度/组可见性正确；共享资产一致；剖面不是凭空断开结构。
- [ ] 运动：短关键动作 proof；始中末、方向、接触和速度连续；动作状态符合因果先后。
- [ ] 相机/标注：真实部件投影误差阈值；标签和箭头不遮关键机制、不进入字幕区；标记与状态同步。
- [ ] 配音：音频负责人；冻结文字/精确转录/参考来源许可/hash；FP32等参数、候选、实际时长、RMS/峰值和有声段质量记录。
- [ ] 人工试听：逐句听自然度、复合词、漏字重复、突兀停顿、响度和切点；技术 PASS/ASR 不代替。
- [ ] 时间轴：同一成片时钟；思考时窗；两语言槽位；字幕无漏项/重叠；改文改音同步。
- [ ] 编码：ffprobe 分辨率/fps/实际时长/音轨；完整流解码；最终编码帧复核；诚实标原生 vs 补帧。
- [ ] 浏览器：真实播放中文/英文、暂停/拖动/章节、快速切换、键盘、静音/音量/速率、结束/重播、全屏、手机视口；错误/超时/手动重试/取消/晚到请求。
- [ ] 离线：按需加载与明确下载；首次外壳不取巨大媒体；源包不入运行清单；推荐的项目适配版与原始归档分列，原件 hash 不变，派生版每个嵌入 payload 等价；全新浏览器断网 file:// 中英播放。
- [ ] 离线控件：可信 touchStart→touchMove→touchCancel/lost capture 不冻结进度；暂停/播放/结束/Seek/原生密集键盘/快切与同页恢复；桌面/390px 手机/平板/reduced-motion 的语言与章节目标均≥44px、Tab 焦点可见；实体设备另验。
- [ ] 密集定位与恢复：fresh 中英同输入组合；每次输入目标保真/无按键间等待，原生最终帧和媒体钟验证；允许合法合并在途请求但不丢逻辑输入。真实 waiting 有界、中英可见反馈、旁白停止、手动重试保暂停意图、取消/晚到请求不复活；故障网络fixture与实际冷离线文件验收分列。
- [ ] PWA：实际接收最新主线生成资产清单和 versioned SW import；精确 query/key/200-only/Range/Vary 契约与已有书/实验室回归，不用旧基线清单盖主线。
- [ ] 全屏与焦点：真实 Permissions-Policy 拒绝下 fallback；按钮、range/select/link/summary 聚焦时 trusted Escape 退出；其他键保留原生控件行为。原生允许与拒绝路径分别留证。
- [ ] 退役：精确 SHA/bytes 删除白名单与可恢复副本先验；旧目录卡片/链接/chunk/构建清单不再运行或发布；独立 film-only inventory。不全清缓存；普通关闭/重开升级仅清退役路径及别名/query，其他下载、32 条索道 versioned 音频、四种删除状态和 localStorage 保留，退役 URL 410 不可再缓存。
- [ ] 封存：源码/输入/工具环境/媒体/字幕/方法/测试/父版本 raw SHA+bytes；失败原证据保留；独立 QA 回执另列。
- [ ] 发布：单文件/托管限制已确认；提交、推送、PR、合并、发布分别获授权；CI/远端文件/最终地址验证。
