# 火箭、高铁、校车 3D 实验室

沿用飞机实验室的交互，新增三个独立模型。每个模型包含可选关键部件、双语介绍、英文朗读、拆解复原与五题挑战。

新增共享 `labs/shared/page.js` 和 `explorer.js`：页面结构、相机、选取、标签、拆解、进度及挑战由共享代码处理；各主题 `parts.js` 提供配置与教学内容，`model.js` 仅负责几何与拆解偏移。既有飞机实验室保持可用。

目录登记更新为四个已开放主题，三个对应绘本加入跳转入口。预览图从实际模型渲染生成。发布前检查各部件确有可选模型、坐标有效、标签和文案匹配，进行整机/拆解桌面及手机截图检查，再测试公开路径导航与现有绘本。

火箭、高铁、校车形状及部件关系为教学简化，具体构型会在各页面说明。英文使用儿童可读的短句，说明来源由各主题配置登记。
