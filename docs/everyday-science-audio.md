## 声线与处理

使用 Fun-CosyVoice 3。本批沿用获认可的新版小样配方：温柔成年女声旁白；咚咚使用明亮少年男声指令，松鼠使用轻盈年轻男声指令，沫沫使用明亮少女声指令，妈妈使用沉稳成年女声指令。这是合成方向，不保证每位听者都感知到对应年龄。

中文角色参考来自此前项目的 AISHELL-3 参考片段，旁白沿用已有 CosyVoice 示例参考。英文沿用 Kara / LibriTTS speaker 19 参考并区分角色指令，不声称有四位不同英语参考说话人。参考录音只用于本地生产，不随绘本分发；沿用既有素材不构成新增的权利清理或人物背书声明。

中文仅施加 8 ms 首尾渐变；英文另采用 70 Hz 二阶高通和温和频谱处理，保持片段长度。每段 RMS 目标 0.095、峰值限制 0.94，开头留白 0.1 秒，段间留白 0.18 秒。原始段与 WAV 母版保留在本地，不进入离线包或 GitHub 本次提交。

六条获认可的 clean 小样精确复用于正式文件。用户对小样配方的认可不等于逐条听过全部 66 条正式音频。独立验收覆盖 129 个实际分段：原文、角色、参考文件身份、增益与处理重算，以及最终音频完整解码。阅读器与离线缓存的浏览器验收独立记录，不以文件存在代替播放通过。
