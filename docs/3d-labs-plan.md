# 3D 实验室整合与发布

目标：在现有静态绘本网站新增独立 3D 实验室板块，发布飞机实验室，并让火箭、高铁等主题能够按约定逐个加入。

结构：`books/` 继续存放绘本；`labs/index.html` 是实验室目录；`labs/catalog.js` 登记主题与发布状态；`labs/<id>/` 保存各主题模型、讲解及页面。共享样式、导航、语音和固定版本 Three.js 存放于 `labs/shared/`。目录不会预加载 WebGL。
