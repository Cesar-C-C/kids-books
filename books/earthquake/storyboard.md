# 岩岩的博物馆：v2 分镜与展示

保留暖棕鳞片、青绿色围裙的岩岩与自然博物馆空间。复用已审阅的四张博物馆插画；科学证据由独立 SVG 模型产生，不叠在人物上，也不把插画里的岩块排列当物理几何。

| 场景 | 情节与因果 | 展示形式 |
| --- | --- | --- |
| opening | 布展任务：平稳的大地为何会摇；“有人推大地吗” | 开场全景与岩岩提问 |
| observation | 板块平时缓慢运动；局部断层锁住，周围岩石微小形变并储能 | 角色近景 + 本地“为什么” + 断层观察 |
| fault observation | 先停在锁定形变，再继续看滑移/部分回弹/永久错位 | 同尺度初始灰虚线与当前棕实线；主动作和结果同屏 |
| arrival | 能量的部分去向；岩岩选地下/地表标记与近远旗 | 角色留在展台旁，不再要求摆旗猜题 |
| wave observation | 地下先振动，地表随后振动；两标记未随波跑走 | 同一时钟的空间传播与双局部位移 ×8 窗口；固定到达记录 |
| exhibit | 观众循着原因理解整条链 | 三段可直接读的因果展览，各段能回看证据/展开 why；不排序、不评分 |
| opening-day | 岩岩迎接朋友，复述慢积累、快释放、振动到达 | 已审阅的温暖收尾插画，词汇与成人笔记在后 |

## 操作删留

保留观察动作、暂停、手动小步、重看、切语言、停止、实验室入口和故事继续。取消主线预测选答、选旗/选位置/交换、放卡/前移/验对/帮助排卡、没有新证据的卡片装饰动画。减少动态效果下，主按钮走三个有意义的波观察状态，而不是要求几十次微小点击。

内容源为 story.json / earthquake-story-v2。旧正式 audio-manifest.json 与 MP3 不改；新版内容经本地和独立候选验收稳定后，由音频会话做差异配音，再由 QA 统一集成。
